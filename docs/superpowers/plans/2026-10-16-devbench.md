# devbench Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a browser-only developer toolbox with JSON, time, diff, encode, JWT, and UUID tools.

**Architecture:** Next.js App Router. Pure functions in `lib/` return `ToolResult<T>`. Client pages call those functions and render an inline error or a result. Nothing is fetched.

**Tech Stack:** Next.js App Router, React, TypeScript, Tailwind CSS, pnpm, Vitest, `diff`.

## Global Constraints

- Parsing and formatting live in `lib/` and are covered by Vitest.
- Pages do not catch library exceptions. Libraries return `{ ok: false, error }`.
- No API routes, database, accounts, or environment variables.
- Empty input is idle: no error and no result.
- Invalid input shows one inline message. The page does not throw.
- A copy button appears only when there is a result.
- `pnpm test` and `pnpm build` pass with no environment variables.
- Pasted text never leaves the browser.

### Task 2: JSON, time, encode, JWT, UUID, diff libraries

**Files:**
- Create: `lib/result.ts`, `lib/json.ts`, `lib/time.ts`, `lib/diff.ts`, `lib/encode.ts`, `lib/jwt.ts`, `lib/uuid.ts`
- Test: `lib/*.test.ts`

**Interfaces:**
- Produces:

```ts
export type ToolResult<T> =
  | { ok: true; value: T }
  | { ok: false; error: string }

export function formatJson(input: string): ToolResult<string>
export function minifyJson(input: string): ToolResult<string>

export type EpochUnit = "seconds" | "milliseconds"
export type Instant = { seconds: number; milliseconds: number; utcIso: string }
export function convertEpoch(raw: string, unit: EpochUnit): ToolResult<Instant>
export function convertLocalDateTime(raw: string, timezoneOffsetMinutes: number): ToolResult<Instant>

export type DiffLine = { type: "unchanged" | "added" | "removed"; text: string }
export function diffText(before: string, after: string): ToolResult<DiffLine[]>

export function encodeBase64(input: string): ToolResult<string>
export function decodeBase64(input: string): ToolResult<string>
export function encodeUrl(input: string): ToolResult<string>
export function decodeUrl(input: string): ToolResult<string>

export type JwtDecoded = {
  header: string
  payload: string
  signature: string
  notice: "Signature was not checked."
}
export function decodeJwt(token: string): ToolResult<JwtDecoded>

export function generateUuid(): string
```
